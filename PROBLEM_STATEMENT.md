# Greeting

A tiny exercise used to test the workshop leaderboard's automatic grading end to end. It is not a workshop lesson.

## Your task
Make `Greeting.of(name)` in `src/main/java/com/example/exercise/Greeting.java` return:
- `Hello, <name>!`, with any spaces around the name removed;
- `Hello, world!` when the name is empty, only spaces, or `null`.

## Done when
`./gradlew test` (Windows: `gradlew.bat test`) passes, with the tests in `src/test/` unchanged. Then open a pull request.

## How it is graded
Automatically: the leaderboard runs its own copy of the tests in `src/test/` against your pull request. Nothing here needs a facilitator to check by hand.
